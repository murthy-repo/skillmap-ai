# SkillMap AI: B.Tech Upskilling & Community Platform

**SkillMap AI** is an intelligent, local-first upskilling and community platform designed specifically for B.Tech students. It leverages local AI models and vector databases to provide personalized learning roadmaps, interactive AI guidance, and community features—all running privately and securely on your local machine.

---

## 🚀 Key Features

* **Local AI Integration:** Powered by **Gemma 3:1B** via Ollama for fast, privacy-focused, zero-cost AI inference.
* **Smart RAG (Retrieval-Augmented Generation):** Utilizes **ChromaDB** to store and retrieve contextual data locally.
* **Interactive B.Tech Upskilling:** Get structured roadmaps, study resources, and real-time answers tailored to engineering coursework and tech career paths.
* **Community Platform:** Built-in features allowing students to collaborate, share progress, and stay on track with their academic and professional goals.
* **Zero-Loss Local Storage:** FastAPI backend integrated with robust local JSON and SQLite state management.

---

## 🛠️ Tech Stack

* **Backend:** FastAPI, Python, Requests, Pydantic
* **AI & Database:** Ollama (Gemma 3:1B), ChromaDB (Vector Store)
* **Frontend:** HTML5, Modern CSS, JavaScript
* **Version Control:** Git & GitHub
